# Прайси постачальників файлами

Сюди кладуть прайси, які постачальник надсилає файлом: XML, YML, CSV або Excel.
Після завантаження файлу впишіть шлях до нього в `config.json`:

```json
{ "id": "agro", "label": "Агро-Люкс", "file": "feeds/agro.xlsx" }
```

Скрипт сам знайде колонки з назвою, ціною, артикулом і наявністю за заголовками.
Якщо заголовки нестандартні, вкажіть їх явно:

```json
{ "id": "agro", "label": "Агро-Люкс", "file": "feeds/agro.xlsx",
  "columns": { "name": "Найменування", "price": "Опт", "code": "Артикул", "avail": "Залишок" } }
```
